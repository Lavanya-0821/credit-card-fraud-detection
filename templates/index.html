ABOUT PROJECT

How Our System Works

A Machine Learning based system designed to identify fraudulent credit card transactions.

🤖

Machine Learning

Random Forest classification is used to identify whether a transaction is normal or fraudulent.

📊

Dataset

The system uses credit card transaction data containing normal and fraudulent transactions.

⚖️

SMOTE

SMOTE handles the highly imbalanced dataset by generating synthetic fraud samples during training.

📈

Model Evaluation

Accuracy, Precision, Recall, F1-Score and ROC-AUC are used to evaluate the model.
